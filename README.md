# App Store uploads

Store texts (14 languages) and framed screenshots for Tabela, Piti Piti, Tesbih and Refleks,
uploaded to App Store Connect by GitHub Actions.

Actions → "Upload App Store texts" / "Upload App Store screenshots" → app_id + folder.
Secrets needed: ASC_KEY_ID, ASC_ISSUER_ID, ASC_PRIVATE_KEY.
